## Notes

- Save each image as **WEBP** format with the exact filename above.
- Recommended dimensions match the approximate aspect ratios noted (hero: wide banner; phone: narrow strip; examples: 2:1 card proportions).
- The CSS layers these images under gradient overlays, so slightly desaturated or softer images work well — the overlays will tint them.
- The placeholder images currently in `public/` are simple gradients — replace them with your generated images and delete the `generate-placeholder-images.py` script once done.
