# Funeral Resources

## Goal

Reserve vehicles and assets for each funeral from a single planning screen, prevent double booking, and track what goes out and comes back on funeral day.

**Estimated time:** 15 minutes  
**Requirements:** An authorised funeral home account. Vehicles and assets must already be added (see [Vehicles & Assets](14-vehicles-and-assets.md)).

## Overview

The **Funeral Resources** page links operations to memorials. When a funeral is created, staff can reserve the hearses, cars, chairs, tents, sound systems, and other equipment needed for that service — all in one place.

## Selecting a Memorial

1. Open **Funeral Resources** in the sidebar.
2. Use the search box to find and select the memorial (by the deceased's name).
3. The screen loads the memorial's details, including the service date.

## Reserving Resources

1. In the **Vehicles** column, tick each vehicle required (for example "Hearse 01").
2. In the **Assets** column, tick each asset required and set the **quantity** (for example 120 chairs).
3. Review the availability badge next to each selection:
   - Green **Available** - no scheduling conflict.
   - Red **Unavailable** - the resource is already reserved for this period.
4. Add a note for the operations team if needed.
5. Click **Reserve Selected**.

> **Tip:** Run the availability check before reserving so conflicting items are visible ahead of time.

## Reservation Statuses

Each reservation moves through these statuses:

| Status | Meaning |
|---|---|
| Reserved | Assigned to the memorial but not yet collected. |
| Checked Out | Collected and in use for the funeral. |
| Returned | Brought back after the service. |
| Cancelled | No longer needed. |

## Managing Reservations

1. On the **Funeral Resources** page, scroll to **Current Reservations**.
2. Use the row actions to:
   - **Check Out** - mark the vehicle or asset as collected on funeral day.
   - **Return** - mark it as returned after the service.
   - **Cancel** - remove the reservation if it is no longer needed.
3. Deleting a reservation removes it from the list entirely.

## Preventing Double Booking

- The system refuses to create a second active reservation for the same vehicle or asset against the same memorial.
- Resources that are already reserved or checked out show as **Unavailable** in the availability check.

> **Warning:** Availability is based on reservations in the system. Keep reservation statuses up to date on funeral day so future availability checks stay accurate.

## Common Mistakes

- Reserving a vehicle while it is still marked **In Maintenance** in Vehicle Management.
- Selecting assets without setting the quantity (chairs and tables usually need more than one).
- Forgetting to check resources back in as **Returned** after the service.
- Skipping the availability check and only noticing conflicts when a second reservation is blocked.
