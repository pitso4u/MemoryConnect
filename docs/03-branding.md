# Branding

## Goal

Apply the funeral home's identity consistently to admin, family, and public memorial pages.

**Estimated time:** 15 minutes  
**Requirements:** Funeral Home Admin access, approved logo URL, brand colours, and contact details.

![Brand Studio](images/branding.png)

## Choose a Theme

1. Open **Profile & Branding**.
2. Find **Brand Studio**.
3. Review the available templates.
4. Select the template closest to the funeral home's style.
5. Continue with the detailed settings below.

Available templates may include Classic, Elegant, Modern, Luxury, Gold, Dark, Minimal, Traditional African, Church, and Corporate.

## Update Identity and Contact Details

1. Enter the company and trading names.
2. Add the company email and telephone number.
3. Add WhatsApp and the physical address.
4. Add website and official social links.

## Update Colours and Style

1. Select primary, secondary, accent, background, and text colours.
2. Choose an approved font family.
3. Choose button, card, gallery, programme, and animation styles.
4. Use the desktop, mobile, public, admin, and PDF preview controls.

> **Tip:** Use strong contrast between text and background colours. A decorative colour should not make text difficult to read.

## Add Logos and Backgrounds

Add approved URLs for:

- Main logo and icon.
- Home and login backgrounds.
- Memorial hero image.
- Projector background.
- PDF watermark.
- Splash screen.

## Save and Check

1. Select **Save brand profile**.
2. Wait for **Brand profile saved**.
3. Open a memorial preview.
4. Check the logo, colours, text, and buttons on a phone and computer.

## Notes

> **Warning:** White-label settings affect how Memory Connect attribution appears. Use only the option approved for the funeral home's account.

## Common Mistakes

- Using a low-resolution logo.
- Pasting a local computer file path instead of a web URL.
- Choosing text and background colours with poor contrast.
- Forgetting to save after previewing.

## Best Practices

- Use a transparent PNG logo where possible.
- Keep colours consistent with printed funeral programmes.
- Use subtle animation for formal memorials.
- Check long funeral home names in the mobile preview.
